# Standalone Animal Company Developer Canvas Mod

A structural starter project layout designed for deploying standalone runtime C# interfaces within local client configurations.

## Framework Prerequisites
* Compiled to target `.NET Framework 4.7.2`
* Intended for compilation integration with `MelonLoader` environment engines

## Controls
* Press **Insert** on your connected keyboard interface to open or close the overlay canvas layout.
